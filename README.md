### SwiftKit

Small, honest data tools built on **official APIs and open data**. No logins, no CAPTCHAs, no
personal-data lists. Hosted versions run on [Apify](https://apify.com/swiftkit), pay per result.

**Free examples (MIT)**

- [sec-edgar-financials](https://github.com/swiftkit-dev/sec-edgar-financials): US company financials to CSV from SEC EDGAR, with the XBRL traps handled
- [shopify-catalog-export](https://github.com/swiftkit-dev/shopify-catalog-export): any Shopify store's catalog to CSV
- [eu-fuel-prices](https://github.com/swiftkit-dev/eu-fuel-prices): cheapest fuel near a point in France, Spain and Italy
- [whisper-cpu-transcribe](https://github.com/swiftkit-dev/whisper-cpu-transcribe): audio/video to text, SRT and VTT on a plain CPU
- [product-price-jsonld](https://github.com/swiftkit-dev/product-price-jsonld): price and stock from almost any product page
- [wikidata-company-lookup](https://github.com/swiftkit-dev/wikidata-company-lookup): company name to website, logo and facts
- [website-tech-stack-detector](https://github.com/swiftkit-dev/website-tech-stack-detector): what a website is built with
